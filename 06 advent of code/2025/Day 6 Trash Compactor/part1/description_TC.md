# --- 第六天：垃圾壓縮機 (Trash Compactor) ---

在廚房幫完小精靈後，你正在休息並幫他們重演電影場景，結果你太過熱情地跳進了垃圾滑槽！

短暫的墜落後，你發現自己身處在垃圾粉碎機中。不幸的是，門已經被磁力密封了。

當你試圖尋找出路時，一個頭足類動物（cephalopods）家庭接近了你！他們很確定他們能把門打開，但這需要一些時間。在等待的同時，他們很好奇你能不能幫他們家中最小的成員做她的[數學作業](https://adventofcode.com/2021/day/18)。

頭足類動物的數學看起來與普通數學沒什麼不同。數學學習單（你的拼圖輸入）包含一系列的**問題**；每個問題都有一組數字，需要將它們**相加** (`+`) 或 **相乘** (`*`)。

然而，問題的排列方式有點奇怪；它們似乎在一個非常長的水平列表中並排呈現。例如：

```text
123 328  51 64 
 45 64  387 23 
  6 98  215 314
*   +   *   +
```

每個問題的數字是垂直排列的；在問題的底部是需要執行的運算符號。問題之間由一整列的空格分隔。每個問題內數字的左/右對齊可以忽略。

所以，這張學習單包含四個問題：

- `123` \* `45` \* `6` = `33210`
- `328` + `64` + `98` = `490`
- `51` \* `387` \* `215` = `4243455`
- `64` + `23` + `314` = `401`

為了檢查他們的作業，頭足類學生會得到將各個問題的所有答案加在一起的**總計**。在這張學習單中，總計是 `33210` + `490` + `4243455` + `401` = `4277556`。

當然，實際的學習單要寬得**多**。你需要確保將其完全展開，以便清楚地閱讀問題。

解決數學學習單上的問題。**將各個問題的所有答案加在一起所得到的總計是多少？**
