# --- 第二部分 ---

大頭足類動物回來檢查進展如何。當他們看到你的總計與學習單預期的不符時，他們意識到他們忘了解釋如何閱讀頭足類數學。

頭足類數學是**在列中從右到左**書寫的。每個數字都在自己的列中，最高位數在頂部，最低位數在底部。（問題仍然由一整列的空格分隔，問題底部的符號仍然是要使用的運算子。）

再次看看這個學習單範例：

```text
123 328  51 64 
 45 64  387 23 
  6 98  215 314
*   +   *   +  
```

從右到左一次讀取一列問題，現在問題變得相當不同：

- 最右邊的問題是 `4` + `431` + `623` = `1058`
- 右邊第二個問題是 `175` \* `581` \* `32` = `3253600`
- 右邊第三個問題是 `8` + `248` + `369` = `625`
- 最後，最左邊的問題是 `356` \* `24` \* `1` = `8544`

現在，總計是 `1058` + `3253600` + `625` + `8544` = `3263827`。

再次解決數學學習單上的問題。**將各個問題的所有答案加在一起所得到的總計是多少？**
