# --- 第二部分 ---

精靈們是對的；他們**絕對**沒有足夠的延長線。你需要繼續將接線盒連接在一起，直到它們全部都納入**一個大型電路**中。

延續上面的例子，第一個使所有接線盒形成單一電路的連接，是位於 `216,146,977` 和 `117,168,530` 的接線盒之間的連接。精靈們需要知道那些接線盒離牆多遠，以便他們能選擇正確的延長線；將這兩個接線盒的 X 座標（`216` 和 `117`）相乘，得到 **`25272`**。

繼續將最靠近的、尚未連接的接線盒對連接在一起，直到它們全部都在同一個電路中。**如果你將最後需要連接的兩個接線盒的 X 座標相乘，你會得到什麼？**
