# --- 第二部分 ---

精靈們剛剛想起：他們只能更換**紅色**或**綠色**的瓷磚。所以，你的矩形只能包含紅色或綠色的瓷磚。

在你的列表中，每個紅色瓷磚都通過一條直線的**綠色瓷磚**連接到它之前和之後的紅色瓷磚。列表是循環的，所以第一個紅色瓷磚也連接到最後一個紅色瓷磚。列表中相鄰的瓷磚將始終位於同一行或同一列。

使用與之前相同的例子，標記為 `X` 的瓷磚將是綠色：

```text
..............
.......#XXX#..
.......X...X..
..#XXXX#...X..
..X........X..
..#XXXXXX#.X..
.........X.X..
.........#X#..
..............
```

此外，這個紅色和綠色瓷磚循環**內部**的所有瓷磚**也**是綠色。所以，在這個例子中，這些是綠色瓷磚：

```text
..............
.......#XXX#..
.......XXXXX..
..#XXXX#XXXX..
..XXXXXXXXXX..
..#XXXXXX#XX..
.........XXX..
.........#X#..
..............
```

其餘的瓷磚既不是紅色也不是綠色。

你選擇的矩形仍然必須在對角有紅色瓷磚，但它包含的任何其他瓷磚現在必須是紅色或綠色。這大大限制了你的選擇。

例如，你可以在 `7,3` 和 `11,1` 之間製作一個由紅色和綠色瓷磚組成的面積為 `15` 的矩形：

```text
..............
.......OOOOO..
.......OOOOO..
..#XXXXOOOOO..
..XXXXXXXXXX..
..#XXXXXX#XX..
.........XXX..
.........#X#..
..............
```

或者，你可以在 `9,7` 和 `9,5` 之間製作一個面積僅為 `3` 的薄矩形：

```text:
..............
.......#XXX#..
.......XXXXX..
..#XXXX#XXXX..
..XXXXXXXXXX..
..#XXXXXXOXX..
.........OXX..
.........OX#..
..............
```

在這個例子中，你只能使用紅色和綠色瓷磚製作的最大矩形面積是**`24`**。其中一種方法是在 `9,5` 和 `2,3` 之間：

```text
..............
.......#XXX#..
.......XXXXX..
..OOOOOOOOXX..
..OOOOOOOOXX..
..OOOOOOOOXX..
.........XXX..
.........#X#..
..............
```

使用兩個紅色瓷磚作為對角，**你能製作的任何矩形的最大面積是多少，僅使用紅色和綠色瓷磚？**
