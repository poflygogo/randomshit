# --- 第二天：禮品店 (Gift Shop) ---

你進去後搭乘電梯到它唯一的另一個停靠站：禮品店。「感謝您造訪北極！」附近的一個標誌愉快地驚呼著。你不確定到底誰被允許造訪北極，但你知道你可以從這裡進入大廳，然後從那裡你可以進入北極基地的其餘部分。

當你穿過令人驚訝的廣泛商品選擇時，其中一位店員認出了你並請求你的幫助。

原來，其中一位年輕的小精靈在玩禮品店的電腦，並設法將一大堆無效的產品 ID 添加到他們的禮品店資料庫中！想必，幫他們找出無效的產品 ID 對你來說應該不是問題，對吧？

他們甚至已經檢查了大部分的產品 ID 範圍；他們只剩下幾個產品 ID 範圍（你的拼圖輸入）需要你來檢查。例如：

```text
11-22,95-115,998-1012,1188511880-1188511890,222220-222224,
1698522-1698528,446443-446449,38593856-38593862,565653-565659,
824824821-824824827,2121212118-2121212124
```

（為了清晰起見，這裡的 ID 範圍被換行了；在你的輸入中，它們出現在單獨的一長行上。）

範圍用逗號（`,`）分隔；每個範圍給出它的**第一個 ID** 和**最後一個 ID**，中間用連字號（`-`）分隔。

因為年輕的小精靈只是在做愚蠢的模式，你可以透過尋找任何僅由某個數字序列重複兩次組成的 ID 來找到**無效 ID**。所以，`55`（`5` 兩次）、`6464`（`64` 兩次）和 `123123`（`123` 兩次）都將是無效 ID。

沒有數字有前導零；`0101` 根本不是一個 ID。（`101` 是一個你會忽略的有效 ID。）

你的工作是找出出現在給定範圍內的所有無效 ID。在上面的例子中：

- `11-22` 有兩個無效 ID，`11` 和 `22`。
- `95-115` 有一個無效 ID，`99`。
- `998-1012` 有一個無效 ID，`1010`。
- `1188511880-1188511890` 有一個無效 ID，`1188511885`。
- `222220-222224` 有一個無效 ID，`222222`。
- `1698522-1698528` 不包含無效 ID。
- `446443-446449` 有一個無效 ID，`446446`。
- `38593856-38593862` 有一個無效 ID，`38593859`。
- 其餘的範圍不包含無效 ID。

將這個例子中的所有無效 ID 相加會產生 `1227775554`。
