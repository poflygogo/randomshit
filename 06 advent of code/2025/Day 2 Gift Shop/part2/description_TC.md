# --- 第二部分 ---

店員很快發現你的清單範圍中仍然有無效的 ID。也許那位年輕的小精靈也做了其他愚蠢的模式？

現在，如果一個 ID 僅由某個數字序列重複**至少**兩次組成，則該 ID 是無效的。所以，`12341234`（`1234` 兩次）、`123123123`（`123` 三次）、`1212121212`（`12` 五次）和 `1111111`（`1` 七次）都是無效 ID。

使用與之前相同的例子：

- `11-22` 仍然有兩個無效 ID，`11` 和 `22`。
- `95-115` 現在有兩個無效 ID，`99` 和 `111`。
- `998-1012` 現在有兩個無效 ID，`999` 和 `1010`。
- `1188511880-1188511890` 仍然有一個無效 ID，`1188511885`。
- `222220-222224` 仍然有一個無效 ID，`222222`。
- `1698522-1698528` 仍然不包含無效 ID。
- `446443-446449` 仍然有一個無效 ID，`446446`。
- `38593856-38593862` 仍然有一個無效 ID，`38593859`。
- `565653-565659` 現在有一個無效 ID，`565656`。
- `824824821-824824827` 現在有一個無效 ID，`824824824`。
- `2121212118-2121212124` 現在有一個無效 ID，`2121212121`。

將這個例子中的所有無效 ID 相加會產生 `4174379265`。
