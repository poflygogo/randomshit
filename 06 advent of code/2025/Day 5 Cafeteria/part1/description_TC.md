# --- 第五天：自助餐廳 (Cafeteria) ---

當堆高機打破牆壁時，小精靈們很高興地發現另一邊真的有一個自助餐廳。

你可以聽到廚房傳來一陣騷動。「照這樣下去，我們就沒有時間在餐廳掛花環了！」你堅定地繼續你的任務，前去調查。

「要是我們沒有在聖誕節前夕換成新的庫存管理系統就好了！」另一個小精靈驚呼道。你問發生了什麼事。

廚房裡的小精靈解釋了情況：因為他們複雜的新庫存管理系統，他們搞不清楚哪些食材是**新鮮**的，哪些是**腐壞**的。當你詢問它是如何運作時，他們給了你一份他們的資料庫副本（你的拼圖輸入）。

資料庫基於**食材 ID** 運作。它包含一份**新鮮食材 ID 範圍**的清單、一個空行，以及一份**可用食材 ID** 的清單。例如：

```text
3-5
10-14
16-20
12-18

1
5
8
11
17
32
```

新鮮 ID 範圍是**包含頭尾的 (inclusive)**：範圍 `3-5` 表示食材 ID `3`、`4` 和 `5` 都是**新鮮**的。範圍也可以**重疊**；如果一個食材 ID 位於**任何**範圍內，它就是新鮮的。

小精靈們正試圖確定哪些**可用食材 ID** 是**新鮮**的。在這個例子中，判斷如下：

- 食材 ID `1` 是腐壞的，因為它不屬於任何範圍。
- 食材 ID `5` 是**新鮮**的，因為它屬於範圍 `3-5`。
- 食材 ID `8` 是腐壞的。
- 食材 ID `11` 是**新鮮**的，因為它屬於範圍 `10-14`。
- 食材 ID `17` 是**新鮮**的，因為它屬於範圍 `16-20` 以及範圍 `12-18`。
- 食材 ID `32` 是腐壞的。

所以，在這個例子中，`3` 個可用食材 ID 是新鮮的。

處理來自新庫存管理系統的資料庫檔案。**有多少個可用食材 ID 是新鮮的？**
