# --- 第二部分 ---

手扶梯一動也不動。小精靈解釋說，它可能需要更多的焦耳電壓來克服系統的 [靜摩擦力](https://en.wikipedia.org/wiki/Stiction)，並按下了一個紅色的大按鈕：「焦耳電壓限制安全解除」。你數不清她需要確認多少次「是的，我確定」，於是你在等待的時候稍微裝飾了一下大廳。

現在，你需要透過在每一組電池中開啟**恰好十二個**電池來製造最大的焦耳電壓。

該組的焦耳電壓輸出仍然是由你開啟的電池上的數字所組成的數值；唯一的區別是現在每一組的焦耳電壓輸出將會有 `12` 位數，而不是兩位。

再次考慮之前的例子：

```text
987654321111111
811111111111119
234234234234278
818181911112111
```

現在，焦耳電壓大得多了：

- 在 `987654321111111` 中，可以透過開啟除了末尾的一些 `1` 以外的所有電池來找到最大的焦耳電壓，產生 `987654321111`。
- 在數字序列 `811111111111119` 中，可以透過開啟除了某些 `1` 以外的所有電池來找到最大的焦耳電壓，產生 `811111111119`。
- 在 `234234234234278` 中，可以透過開啟除了開頭附近的一個 `2` 電池、一個 `3` 電池和另一個 `2` 電池以外的所有電池來找到最大的焦耳電壓，產生 `434234234278`。
- 在 `818181911112111` 中，焦耳電壓 `888911112111` 是透過開啟除了前面的一些 `1` 以外的所有電池產生的。

現在總輸出焦耳電壓大得多了：`987654321111` + `811111111119` + `434234234278` + `888911112111` = `3121910778619`。
