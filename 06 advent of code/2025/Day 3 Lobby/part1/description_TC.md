# --- 第三天：大廳 (Lobby) ---

你走下一段短樓梯，進入令人驚訝的寬敞大廳，並迅速通過了安檢站。然而，當你到達主電梯時，你發現每個電梯上方都亮著紅燈：它們全部**離線**了。

「抱歉，」一位小精靈一邊調整附近的控制面板一邊道歉。「某種電力突波似乎把這它們燒壞了。我會試著盡快讓它們恢復上線。」

你解釋說你需要更深入地下。「嗯，你至少可以搭手扶梯下到列印部門，雖然如果沒有電梯，你也走不了多遠。也就是說，如果手扶梯不是也離線的話，你是可以搭的。」

「但是，別擔心！它沒燒壞；它只是需要電力。也許你可以在我繼續修理電梯的時候讓它運作起來。」

附近有電池可以為手扶梯提供這種場合所需的緊急電力。每個電池都標有它們的焦耳電壓（joltage[^1]）等級，數值從 1 到 9。你記下了它們的 [焦耳電壓](https://adventofcode.com/2020/day/10) 等級（你的謎題輸入）。例如：

```text
987654321111111
811111111111119
234234234234278
818181911112111
```

電池被排列成**電池組（banks）**；你輸入中的每一行數字對應單一組電池。在每一組中，你需要開啟**恰好兩個**電池；該組產生的焦耳電壓等於你開啟的電池上的數字所組成的數值。例如，如果你有一組像 12345 這樣的電池，而你開啟了電池 2 和 4，該組將產生 24 焦耳電壓。（你不能重新排列電池。）

你需要找出每一組能產生的最大可能焦耳電壓。在上面的例子中：

- 在 `987654321111111` 中，你可以透過開啟前兩個電池來產生最大可能的焦耳電壓 `98`。
- 在 `811111111111119` 中，你可以透過開啟標有 `8` 和 `9` 的電池來產生最大可能的焦耳電壓，產生 `89` 焦耳電壓。
- 在 `234234234234278` 中，你可以透過開啟最後兩個電池（標記為 `7` 和 `8`）來產生 `78`。
- 在 `818181911112111` 中，你能產生的最大焦耳電壓是 `92`。

總輸出焦耳電壓是每一組最大焦耳電壓的總和，所以在這個例子中，總輸出焦耳電壓是 `98` + `89` + `78` + `92` = `357`。

在你面前有許多電池。找出每一組可能的最大焦耳電壓；**總輸出焦耳電壓是多少？**

[^1]: Joltage 是 Advent of Code 中的虛構單位，結合了 Joule（焦耳，能量單位）與 Voltage（電壓）。此處譯作「焦耳電壓」以保留其與電力相關的雙關含義。
