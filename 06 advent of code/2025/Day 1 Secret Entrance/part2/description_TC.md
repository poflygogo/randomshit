# --- 第二部 ---

你確定那是正確的密碼，但門打不開。你敲門，但沒人回應。你在思考時堆了一個雪人。

當你為你的雪人滾雪球時，你發現了另一份肯定掉在雪地裡的安全文件：

「由於更新的安全協議，請使用密碼方法 0x434C49434B，直至另行通知。」

你記得培訓研討會上說過，「方法 0x434C49434B」意味著你實際上應該計算任何咔噠聲導致轉盤指向 `0` 的次數，無論它是發生在旋轉期間還是在旋轉結束時。

按照上面示例中的相同旋轉，轉盤在其旋轉期間會額外指向零幾次：

- 轉盤開始時指向 `50`。
- 轉盤旋轉 `L68` 指向 `82`；在此旋轉期間，它指向 `0` 一次。
- 轉盤旋轉 `L30` 指向 `52`。
- 轉盤旋轉 `R48` 指向 `0`。
- 轉盤旋轉 `L5` 指向 `95`。
- 轉盤旋轉 `R60` 指向 `55`；在此旋轉期間，它指向 `0` 一次。
- 轉盤旋轉 `L55` 指向 `0`。
- 轉盤旋轉 `L1` 指向 `99`。
- 轉盤旋轉 `L99` 指向 `0`。
- 轉盤旋轉 `R14` 指向 `14`。
- 轉盤旋轉 `L82` 指向 `32`；在此旋轉期間，它指向 `0` 一次。

在這個例子中，轉盤在旋轉結束時指向 `0` 三次，加上在旋轉期間的三次。所以，在這個例子中，新密碼將是 `6`。

小心：如果轉盤指向 `50`，像 `R1000` 這樣的單次旋轉將導致轉盤在返回 `50` 之前指向 `0` 十次！
