# --- 第四天：列印部門 (Printing Department) ---

你搭乘手扶梯下到列印部門。他們顯然正在為聖誕節做準備；到處都有許多大捲紙，角落裡甚至還有一台巨大的印表機（用來處理真正龐大的列印工作）。

這裡的裝飾很容易：他們可以製作自己的裝飾品。你真正需要的是在電梯離線時，能夠更深入北極基地的方法。

「其實，也許我們可以幫上忙，」當你尋求幫助時，其中一位小精靈回答道。「我們很確定後牆的另一邊有一個自助餐廳。如果我們能打破那面牆，你就能繼續前進。可惜我們所有的堆高機都忙著搬運那些大捲紙。」

如果你能優化堆高機的工作，也許他們就會有空閒時間來打破通往自助餐廳的牆。

紙捲（`@`）排列在一個大網格上；小精靈甚至有一張有用的圖表（你的拼圖輸入），標示了所有東西的位置。

例如：

```text
..@@.@@@@.
@@@.@.@.@@
@@@@@.@.@@
@.@@@@..@.
@@.@@@@.@@
.@@@@@@@.@
.@.@.@.@@@
@.@@@.@@@@
.@@@@@@@@.
@.@.@@@.@.
```

只有在周圍八個相鄰位置中**少於四個紙捲**時，堆高機才能存取該紙捲。如果你能找出堆高機可以存取哪些紙捲，他們就會花更少的時間尋找，而有更多的時間打破通往自助餐廳的牆。

在這個例子中，有 `13` 個紙捲可以被堆高機存取（標記為 `x`）：

```text
..xx.xx@x.
x@@.@.@.@@
@@@@@.x.@@
@.@@@@..@.
x@.@@@@.@x
.@@@@@@@.@
.@.@.@.@@@
x.@@@.@@@@
.@@@@@@@@.
x.x.@@@.x.
```

考慮你完整的紙捲位置圖表。**有多少個紙捲可以被堆高機存取？**
