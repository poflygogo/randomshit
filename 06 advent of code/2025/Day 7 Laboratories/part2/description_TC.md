# --- 第二部 ---

完成流形分析後，你開始修復傳送器。然而，當你打開傳送器的側面準備更換損壞的流形時，你驚訝地發現它不是一個經典的快子流形——它是一個**量子快子流形**。

在量子快子流形中，只有**單個快子粒子**被發送通過流形。快子粒子會**同時**走遇到的每個分流器的左邊和右邊路徑。

由於這是不可能的，手冊建議採用量子快子分裂的多世界詮釋：每當粒子到達分流器時，實際上是**時間本身**分裂了。在一條時間線中，粒子向左走，而在另一條時間線中，粒子向右走。

為了修復流形，你真正需要知道的是，在單個粒子完成它通過流形的所有可能旅程後，活躍的**時間線數量**。

在上面的例子中，有許多時間線。例如，有一條粒子總是向左走的時間線：

```text
.......S.......
.......|.......
......|^.......
......|........
.....|^.^......
.....|.........
....|^.^.^.....
....|..........
...|^.^...^....
...|...........
..|^.^...^.^...
..|............
.|^...^.....^..
.|.............
|^.^.^.^.^...^.
|..............
```

或者，有一條粒子在每個分流器處交替向左和向右走的時間線：

```text
.......S.......
.......|.......
......|^.......
......|........
......^|^......
.......|.......
.....^|^.^.....
......|........
....^.^|..^....
.......|.......
...^.^.|.^.^...
.......|.......
..^...^|....^..
.......|.......
.^.^.^|^.^...^.
......|........
```

或者，有一條粒子最終到達與交替時間線相同的點，但採取了完全不同的路徑到達那裡的時間線：

```text
.......S.......
.......|.......
......|^.......
......|........
.....|^.^......
.....|.........
....|^.^.^.....
....|..........
....^|^...^....
.....|.........
...^.^|..^.^...
......|........
..^..|^.....^..
.....|.........
.^.^.^|^.^...^.
......|........
```

在這個例子中，粒子總共最終停留在 `40` 條不同的時間線上。

將量子快子分裂的多世界詮釋應用於你的流形圖表。**總共，單個快子粒子最終會出現在多少條不同的時間線上？**
