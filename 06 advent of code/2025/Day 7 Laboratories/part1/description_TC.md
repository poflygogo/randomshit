# --- 第 7 天：實驗室 ---

你感謝[頭足類動物](https://adventofcode.com/2021/day/1)的幫助，離開了垃圾壓縮機，發現自己身處北極研究翼[熟悉的大廳](https://adventofcode.com/2024/day/6)。

根據那個寫著「傳送樞紐」的大標誌，他們似乎正在研究傳送技術；你忍不住想親自試試，於是踏上了那個巨大的黃色傳送墊。

突然間，你發現自己身處一個陌生的房間！這個房間沒有門；唯一的出路是傳送器。不幸的是，傳送器似乎洩漏了[魔煙](https://en.wikipedia.org/wiki/Magic_smoke)。

既然這是一個傳送實驗室，周圍散落著大量的備件、手冊和診斷設備。連接其中一個診斷工具後，它熱心地顯示出錯誤代碼 `0H-N0`，這顯然意味著其中一個**快子流形**[^1]（tachyon manifolds）出了問題。

你迅速找到了一張快子流形的圖表（你的拼圖輸入）。一束快子束在標記為 `S` 的位置進入流形；快子束總是**向下**移動。快子束可以自由通過空白空間（`.`）。然而，如果快子束遇到一個分流器（`^`），光束就會停止；取而代之的是，新的快子束會從分流器的緊左邊和緊右邊繼續延伸。

例如：

```text
.......S.......
...............
.......^.......
...............
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

在這個例子中，入射的快子束（`|`）從 `S` 向下延伸，直到它到達第一個分流器：

```text
.......S.......
.......|.......
.......^.......
...............
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

在那一點，原本的光束停止了，兩束新的光束從分流器發射出來：

```text
.......S.......
.......|.......
......|^|......
...............
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

這些光束繼續向下，直到它們到達更多的分流器：

```text
.......S.......
.......|.......
......|^|......
......|.|......
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

此時，這兩個分流器總共只產生了**三束**快子束，因為它們都將快子傾倒到它們之間的同一個位置：

```text
.......S.......
.......|.......
......|^|......
......|.|......
.....|^|^|.....
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

這個過程一直持續到所有的快子束都到達分流器或離開流形：

```text
.......S.......
.......|.......
......|^|......
......|.|......
.....|^|^|.....
.....|.|.|.....
....|^|^|^|....
....|.|.|.|....
...|^|^|||^|...
...|.|.|||.|...
..|^|^|||^|^|..
..|.|.|||.|.|..
.|^|||^||.||^|.
.|.|||.||.||.|.
|^|^|^|^|^|||^|
|.|.|.|.|.|||.|
```

為了修復傳送器，你首先需要了解快子流形的分束特性。在這個例子中，一束快子束總共分裂了 `21` 次[^2]。

分析你的流形圖表。**光束將被分裂多少次？**

[^1]: Tachyon（快子）是理論上的超光速粒子；Manifold（流形）是數學拓樸概念。保留原文以便對照拼圖輸入的變數名稱。

[^2]: 這個例子中的輸出是 `21`，而不是 `22`，因為最底下那一排分流器中，有一個並沒有接觸到光束，不會產生分裂(所以答案不是`^`的總數 `22`)。
