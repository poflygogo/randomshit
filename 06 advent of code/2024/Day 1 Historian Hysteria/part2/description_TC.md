# --- 第二部分 ---

你的分析證實了大家最擔心的事情：這兩份地點 ID 清單確實非常不同。

但真的是這樣嗎？

歷史學家們無法就哪一組犯了錯，或是如何解讀長官大部分的手寫字達成共識，但在這陣騷動中，你注意到了一個有趣的細節：許多地點 ID 在兩份清單中都出現了！也許其他的數字根本不是地點 ID，而是被誤讀的手寫字。

這一次，你需要弄清楚左邊清單中的每個數字在右邊清單中出現的確切次數。計算總相似度分數的方法是：將左邊清單中的每個數字，乘以該數字在右邊清單中出現的次數，然後將這些結果加總起來。

再次使用相同的範例清單：

```text
3   4
4   3
2   5
1   3
3   9
3   3
```

對於這些範例清單，計算相似度分數的過程如下：

- 左邊清單的第一個數字是 `3`。它在右邊清單中出現了三次，所以相似度分數增加 `3 * 3 = 9`。
- 左邊清單的第二個數字是 `4`。它在右邊清單中出現了一次，所以相似度分數增加 `4 * 1 = 4`。
- 左邊清單的第三個數字是 `2`。它沒有在右邊清單中出現，所以相似度分數不增加（`2 * 0 = 0`）。
- 第四個數字 `1` 也沒有在右邊清單中出現。
- 第五個數字 `3` 在右邊清單中出現了三次；相似度分數增加 `9`。
- 最後一個數字 `3` 在右邊清單中出現了三次；相似度分數再次增加 `9`。

因此，對於這些範例清單，此過程結束時的相似度分數為 `31` (`9 + 4 + 0 + 0 + 9 + 9`)。

再次考慮你的左邊和右邊清單。它們的相似度分數是多少？
