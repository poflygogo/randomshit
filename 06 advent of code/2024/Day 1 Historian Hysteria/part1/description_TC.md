# --- 第一天：史學家歇斯底里 ---

首席史學家總是在聖誕雪橇盛大啟航時出席，但已經好幾個月沒人見到他了！最後一次聽說，他正在參觀對北極具有歷史意義的地點；一群資深史學家邀請您陪同他們，一起去查看他们認為他最可能造訪的地方。

每當檢查完一個地點，他們就會在清單上用一顆星號標記。他們推測首席史學家肯定在他們要找的前五十個地方之一，所以為了拯救聖誕節，你需要在聖誕老人於12月25日起飛前，幫助他們在清單上集滿五十顆星。

透過解謎來收集星星。Advent日曆每天会提供兩個謎題；當你完成第一個謎題後，第二個謎題才會解鎖。每個謎題可獲得一顆星。祝你好運！

你們甚至還沒出發，那群精靈資深史學家就已經遇到問題了：他們要檢查的地點清單目前是空的。最後，有人決定首先該檢查的地方是首席史學家的辦公室。

湧入辦公室後，大家都確認首席史學家確實不見蹤影。取而代之的是，精靈們發現了各式各樣的筆記和具有歷史意義的地點清單！這似乎是首席史學家離開前所做的規劃。或许這些筆記可以用來決定要搜索哪些地點？

在首席史學家的辦公室裡，具有歷史意義的地點並不是用名稱列出，而是用一個稱為地點ID的獨特數字。為了確保不會遺漏任何東西，史學家們分成兩組，各自搜索辦公室，試圖建立自己完整的地點ID清單。

只有一個問題：当把兩份清單並排比對（你的謎題輸入）时，很快就發現這兩份清單並不是很相似。也許你可以幫助史學家們核對他們的清單？

例如：

```text
3   4
4   3
2   5
1   3
3   9
3   3
```

或許這兩份清dan只差了一點點！為了找出答案，將數字配對並測量它們相距多遠。將左邊清單中最小的數字與右邊清單中最小的數字配對，接著是左邊第二小的數字與右邊第二小的数字配對，依此類推。

在每一對中，計算出兩個數字相差多遠；你需要將所有這些距離加總起来。例如，如果你將左邊清單的 `3` 與右邊清單的 `7` 配對，它們的距離是 `4`；如果你將 `9` 與 `3` 配對，距離則是 `6`。

在上面的範例清單中，配對和距離如下：

- 左邊清單最小的數字是 `1`，右邊清單最小的數字是 `3`。它們之間的距離是 `2`。
- 左邊清單第二小的數字是 `2`，右邊清單第二小的數字是另一個 `3`。它們之間的距離是 `1`。
- 兩份清單中第三小的數字都是 `3`，所以它們之間的距離是 `0`。
- 接下来要配對的數字是 `3` 和 `4`，距離為 `1`。
- 兩份清單中第五小的數字是 `3` 和 `5`，距離為 `2`。
- 最後，左邊清單最大的數字是 `4`，而右邊清單最大的數字是 `9`；它們的距離是 `5`。

要找出左邊清單和右邊清單之間的總距離，請將你找到的所有配對之間的距离加總。在上面的範例中，這就是 `2 + 1 + 0 + 1 + 2 + 5`，總距離為 `11`！
