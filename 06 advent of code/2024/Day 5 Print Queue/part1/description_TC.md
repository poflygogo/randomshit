# --- 第五天：列印佇列 (Print Queue) ---

對穀神星上的搜索感到滿意後，學者中隊建議接著掃描地下 17 層的文具堆。

北極列印部門在接近聖誕節的這時候比以往任何時候都忙碌，當歷史學家們繼續搜索這個具有歷史意義的設施時，一位操作著[非常熟悉的印表機](https://adventofcode.com/2017/day/1)的小精靈向你招手。

這位小精靈一定認得你，因為他毫不浪費時間地解釋說，新的雪橇發射安全手冊更新無法正確列印。如果無法更新安全手冊，後果將不堪設想，於是你提供了你的服務。

安全協定清楚地指出，安全手冊的新頁面必須按照非常具體的順序印製。符號 `X|Y` 表示如果頁碼 `X` 和頁碼 `Y` 都要作為更新的一部分產生，那麼頁碼 `X` 必須在頁碼 `Y` 之前的某個時間點印製。

小精靈給了你頁面排序規則以及每次更新中需要產生的頁面（你的拼圖輸入），但他無法弄清楚每次更新的頁面順序是否正確。

例如：

```text
47|53
97|13
97|61
97|47
75|29
61|13
75|53
29|13
97|29
53|29
61|53
97|53
61|29
47|13
75|47
97|75
47|61
75|61
47|29
75|13
53|13

75,47,61,53,29
97,61,53,29,13
75,29,13
75,97,47,61,53
61,13,29
97,13,75,29,47
```

第一部分指定了頁面排序規則，每行一條。第一條規則 `47|53` 表示如果一次更新同時包含頁碼 47 和頁碼 53，那麼頁碼 47 必須在頁碼 53 之前的某個時間點印製。（47 不一定需要緊接在 53 之前；它們之間允許有其他頁面。）

第二部分指定了每次更新的頁碼。因為大多數安全手冊都不同，所以更新中需要的頁面也不同。第一次更新 `75,47,61,53,29` 表示該更新由頁碼 75、47、61、53 和 29 組成。

為了讓印表機盡快運作，請先找出哪些更新已經是正確的順序。

在上面的例子中，第一次更新 (75,47,61,53,29) 的順序是正確的：

- `75` 正確地排在第一位，因為有規則將其他每一頁都放在它後面：`75|47`、`75|61`、`75|53` 和 `75|29`。
- `47` 正確地排在第二位，因為根據 `75|47`，`75` 必須在它前面，而根據 `47|61`、`47|53` 和 `47|29`，其他每一頁都必須在它後面。
- `61` 正確地排在中間，因為 75 和 47 在它前面（`75|61` 和 `47|61`），而 53 和 29 在它後面（`61|53` 和 `61|29`）。
- `53` 正確地排在第四位，因為它在頁碼 29 之前（`53|29`）。
- `29` 是剩下的唯一頁面，因此正確地排在最後。

因為第一次更新不包含某些頁碼，所以涉及那些缺失頁碼的排序規則會被忽略。

根據規則，第二次和第三次更新的順序也是正確的。像第一次更新一樣，它們也沒有包含每一個頁碼，所以只有部分的排序規則適用——在每次更新中，涉及缺失頁碼的排序規則不會被使用。

第四次更新 `75,97,47,61,53` 的順序不正確：它會在 97 之前印製 75，這違反了規則 `97|75`。

第五次更新 `61,13,29` 的順序也不正確，因為它違反了規則 `29|13`。

最後一次更新 `97,13,75,29,47` 的順序不正確，因為違反了多條規則。

出於某種原因，小精靈還需要知道正在印製的每次更新的中間頁碼。因為你目前只印製順序正確的更新，你需要找出每次順序正確的更新的中間頁碼。在上面的例子中，順序正確的更新是：

```text
75,47,61,53,29
97,61,53,29,13
75,29,13
```

這些更新的中間頁碼分別是 `61`、`53` 和 `29`。將這些頁碼相加得到 `143`。

當然，你需要小心：實際的頁面排序規則清單比上面的例子更大且更複雜。

判斷哪些更新已經是正確的順序。如果你將那些順序正確的更新的中間頁碼相加，你會得到什麼？
