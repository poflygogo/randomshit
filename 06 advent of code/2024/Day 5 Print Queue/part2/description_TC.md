# --- 第二部分 ---

當小精靈們開始列印順序正確的更新時，你有一點時間來修復其餘的更新。

對於每個**順序不正確**的更新，使用頁面排序規則將頁碼排成正確的順序。對於上面的例子，這裡是三個順序不正確的更新及其正確的排序：

- `75,97,47,61,53` 變成 `97,75,47,61,53`。
- `61,13,29` 變成 `61,29,13`。
- `97,13,75,29,47` 變成 `97,75,47,29,13`。

在取出**僅有順序不正確的更新**並將它們正確排序後，它們的中間頁碼是 `47`、`29` 和 `47`。將這些相加會產生 `123`。
