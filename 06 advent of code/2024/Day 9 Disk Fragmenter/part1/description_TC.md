# --- 第九天：磁碟碎片 (Disk Fragmenter) ---

再次按下按鈕，你來到了熟悉的走廊，這裡住著一些友善的 [端足類 (amphipods)](https://adventofcode.com/2021/day/23)！好在你們每個人不知怎麼地都得到了自己的個人迷你潛水艇。歷史學家們飛奔而去尋找首席，大部分是直接撞上牆壁。

當歷史學家們迅速弄清楚如何駕駛這些東西時，你注意到一隻端足類在角落裡對著他的電腦掙扎。他正試圖透過壓縮所有檔案來騰出更多連續的可用空間，但他的程式無法運作；你主動提出幫忙。

他向你展示了他已經產生的**磁碟地圖**（你的謎題輸入）。例如：

```text
2333133121414131402
```

磁碟地圖使用緊湊的格式來表示磁碟上**檔案**和**可用空間**的佈局。數字交替表示檔案的長度和可用空間的長度。

所以，像 `12345` 這樣的磁碟地圖將表示一個區塊的檔案，兩個區塊的可用空間，一個三區塊的檔案，四個區塊的可用空間，然後是一個五區塊的檔案。像 `90909` 這樣的磁碟地圖將表示連續三個九區塊的檔案（它們之間沒有可用空間）。

磁碟上的每個檔案還有一個**ID 號碼**，基於它們在重新排列**之前**出現的順序，從 ID `0` 開始。所以，磁碟地圖 `12345` 有三個檔案：一個 ID 為 `0` 的一區塊檔案，一個 ID 為 `1` 的三區塊檔案，和一個 ID 為 `2` 的五區塊檔案。使用一個字元代表每個區塊，其中數字是檔案 ID，`.` 是可用空間，磁碟地圖 `12345` 表示這些個別區塊：

```text
0..111....22222
```

上面的第一個例子 `2333133121414131402`，表示這些個別區塊：

```text
00...111...2...333.44.5555.6666.777.888899
```

端足類想要從磁碟末端**一次將一個檔案區塊**移動到最左邊的可用空間區塊（直到檔案區塊之間沒有間隙）。對於磁碟地圖 `12345`，過程如下：

```text
0..111....22222
02.111....2222.
022111....222..
0221112...22...
02211122..2....
022111222......
```

第一個例子需要更多步驟：

```text
00...111...2...333.44.5555.6666.777.888899
009..111...2...333.44.5555.6666.777.88889.
0099.111...2...333.44.5555.6666.777.8888..
00998111...2...333.44.5555.6666.777.888...
009981118..2...333.44.5555.6666.777.88....
0099811188.2...333.44.5555.6666.777.8.....
009981118882...333.44.5555.6666.777.......
0099811188827..333.44.5555.6666.77........
00998111888277.333.44.5555.6666.7.........
009981118882777333.44.5555.6666...........
009981118882777333644.5555.666............
00998111888277733364465555.66.............
0099811188827773336446555566..............
```

這個檔案壓縮過程的最後一步是更新**檔案系統校驗和**。要計算校驗和，請將這些區塊中的每一個的位置與其包含的檔案 ID 號碼相乘，然後將結果相加。最左邊的區塊位置為 `0`。如果一個區塊包含可用空間，則跳過它。

繼續第一個例子，前幾個區塊的位置乘以其檔案 ID 號碼分別是 `0 * 0 = 0`, `1 * 0 = 0`, `2 * 9 = 18`, `3 * 9 = 27`, `4 * 8 = 32`，依此類推。在這個例子中，校驗和是這些的總和，即 `1928`。

使用他要求的過程壓縮端足類的硬碟。**產生的檔案系統校驗和是多少？**

> （複製/貼上這個拼圖的輸入時要小心；它是一行非常長的文字。）
