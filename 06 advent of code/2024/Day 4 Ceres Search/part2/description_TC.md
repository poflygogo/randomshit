# --- 第二部分 ---

小精靈疑惑地看著你。你是不是誤解了任務？

為了尋找說明，你把單字搜尋翻過來，發現這其實不是一個 XMAS 謎題；這是一個 `X-MAS` 謎題，你應該要找到兩個排成 `X` 形狀的 `MAS`。達成這個目標的一種方式像這樣：

```text
M.S
.A.
M.S
```

在上面的圖表中，無關的字元再次被替換為 `.`。在 `X` 裡面，每個 `MAS` 都可以是正向寫或反向寫的。

這裡是跟之前一樣的例子，但這次保留了所有的 `X-MAS`：

```text
.M.S......
..A..MSMS.
.M.S.MAA..
..A.ASMSM.
.M.S.M....
..........
S.S.S.S.S.
.A.A.A.A..
M.M.M.M.M.
..........
```

在這個例子中，`X-MAS` 出現了 `9` 次。

把單字搜尋從說明面翻回單字搜尋面再試一次。`X-MAS` 出現了多少次？
