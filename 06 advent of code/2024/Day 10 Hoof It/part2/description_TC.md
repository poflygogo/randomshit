# --- 第二部分 ---

馴鹿花了幾分鐘查看你的登山路線圖，然後意識到了什麼，消失了幾分鐘，最後帶著另一張稍微燒焦的紙回來。

這張紙描述了另一種衡量登山口的方法，稱為其 **評分**。一個登山口的評分是從該登山口開始的 **不同登山路線的數量**。例如：

```text
.....0.
..4321.
..5..2.
..6543.
..7..4.
..8765.
..9....
```

上面的地圖只有一個登山口；它的評分是 `3`，因為從那個位置開始恰好有三條不同的登山路線：

```text
.....0.   .....0.   .....0.
..4321.   .....1.   .....1.
..5....   .....2.   .....2.
..6....   ..6543.   .....3.
..7....   ..7....   .....4.
..8....   ..8....   ..8765.
..9....   ..9....   ..9....
```

這是一張只有一個登山口的地圖，評分為 `13`：

```text
..90..9
...1.98
...2..7
6543456
765.987
876....
987....
```

這張地圖包含一個評分為 `227` 的單一登山口（因為有 `121` 條不同的登山路徑通往右邊緣的 `9`，還有 `106` 條通往底邊緣的 `9`）：

```text
012345
123456
234567
345678
4.6789
56789.
```

這是前面那個較大的例子：

```text
89010123
78121874
87430965
96549874
45678903
32019012
01329801
10456732
```

按照閱讀順序考慮其登山口，它們的評分分別為 `20`、`24`、`10`、`4`、`1`、`4`、`5`、`8` 和 `5`。這個較大範例地形圖中所有登山口評分的總和是 **`81`**。

你不知道怎麼回事，但馴鹿似乎用牙籤和紙片製作了一些小旗子，並用它們在你的地形圖上標記登山口。**所有登山口的評分總和是多少？**
