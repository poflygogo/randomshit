當你在工作時，其中一位歷史學家在你看著你的肩膀，問你是否將共振諧波的影響納入計算中。

哎呀！

更新你的模型後，結果發現反節點發生在與至少兩個相同頻率的天線完全成一直線的**任何網格位置**，無論距離為何。這意味著一些新的反節點將發生在每個天線的位置（除非該天線是其頻率中唯一的一個）。

所以，這三個 `T` 頻率的天線現在產生了許多反節點：

```text
T....#....
...T......
.T....#...
.........#
..#.......
..........
...#......
..........
....#.....
..........
```

事實上，這三個 `T` 頻率的天線都與兩個天線完全成一直線，所以它們也都是反節點！這使得上述例子中的反節點總數達到 `9`。

原來的例子現在有 `34` 個反節點，包括出現在每個天線上的反節點：

```text
##....#....#
.#.#....0...
..#.#0....#.
..##...0....
....0....#..
.#...#A....#
...#..#.....
#....#.#....
..#.....A...
....#....A..
.#........#.
...#......##
```

使用這個更新後的模型計算訊號的影響。**在地圖範圍內有多少個唯一位置包含反節點？**
