# --- 第八天：共振共線 (Resonant Collinearity) ---

你們發現自己身處在一個最高機密的復活節兔子設施的[屋頂](https://adventofcode.com/2016/day/25)上。

當歷史學家們忙著他們的事情時，你看了一下那熟悉的**巨大天線**。令你驚訝的是，它似乎被重新配置過，發出的訊號會讓人們購買復活節兔子品牌仿冒平庸巧克力作為聖誕禮物的可能性增加 0.1%！真是不可思議！

掃描整個城市，你發現實際上有很多這樣的天線。每個天線都調諧到一個特定的**頻率**，由單個小寫字母、大寫字母或數字表示。你製作了一張這些天線的地圖（你的謎題輸入）。例如：

```text
............
........0...
.....0......
.......0....
....0.......
......A.....
............
............
........A...
.........A..
............
............
```

該訊號只會根據天線的共振頻率在特定的**反節點 (antinodes)** 處產生其邪惡的影響。具體來說，反節點發生在與兩個相同頻率的天線完全成一直線的任何點上——但前提是其中一個天線的距離是另一個天線的兩倍。這意味著對於任何一對具有相同頻率的天線，會有兩個反節點，分別位於它們的兩側。

所以，對於這兩個頻率為 `a` 的天線，它們產生了標記為 `#` 的兩個反節點：

```text
..........
...#......
..........
....a.....
..........
.....a....
..........
......#...
..........
..........
```

增加第三個相同頻率的天線會產生更多個反節點。理想情況下它會增加四個反節點，但其中兩個超出了地圖的右側，所以它只增加了兩個：

```text
..........
...#......
#.........
....a.....
........a.
.....a....
..#.......
......#...
..........
..........
```

不同頻率的天線不會產生反節點；`A` 和 `a` 算作不同的頻率。然而，反節點**可以**發生在包含天線的位置上。在這張圖中，頻率為大寫 `A` 的孤立天線不會產生反節點，但其位置上有一個小寫 `a` 頻率的反節點：

```text
..........
...#......
#.........
....a.....
........a.
.....a....
..#.......
......A...
..........
..........
```

第一個例子有兩種不同頻率的天線，所以它們產生的反節點看起來像這樣，加上一個與最上方 `A` 頻率天線重疊的反節點：

```text
......#....#
...#....0...
....#0....#.
..#....0....
....0....#..
.#....A.....
...#........
#......#....
........A...
.........A..
..........#.
..........#.
```

因為最上方的 `A` 頻率天線與一個 `0` 頻率反節點重疊，所以在地圖範圍內總共有 `14` 個包含反節點的唯一位置。

計算訊號的影響。**在地圖範圍內有多少個唯一位置包含反節點？**
