# --- 第二部 ---

當歷史學家們開始繞過守衛的巡邏路線工作時，你借用了他們那花俏的裝置並走出了實驗室。在儲藏室的安全掩護下，你穿越回過去幾個月，並在儲藏室的牆上[記錄]([Day 4 - Advent of Code 2018](https://adventofcode.com/2018/day/4))了實驗室守衛崗位的夜間狀態。

回到歷史學家們身邊，感覺只過了幾秒鐘，他們解釋說守衛的巡邏區域實在太大了，如果不被發現，他們無法安全地搜索實驗室。

幸運的是，他們**非常確定**添加一個新的障礙物**不會**導致時間悖論。他們想以某種方式放置新的障礙物，使守衛**陷入循環**，從而使實驗室的其餘部分可以安全搜索。

為了將產生時間悖論的機會降到最低，歷史學家們想知道**所有**可能放置這種障礙物的位置。新的障礙物不能放在守衛的起始位置——守衛現在就在那裡，會注意到的。

在上面的例子中，只有 `6` 個不同的位置放置新障礙物會導致守衛陷入循環。這六種情況的圖表使用 `O` 標記新障礙物，`|` 顯示守衛上下移動的位置，`-` 顯示守衛左右移動的位置，`+` 顯示守衛既上下又左右移動的位置。

選項一，在守衛起始位置旁邊放一台印刷機：

```text
....#.....
....+---+#
....|...|.
..#.|...|.
....|..#|.
....|...|.
.#.O^---+.
........#.
#.........
......#...
```

選項二，在地圖區域的右下象限放一堆失敗的套裝原型：

```text
....#.....
....+---+#
....|...|.
..#.|...|.
..+-+-+#|.
..|.|.|.|.
.#+-^-+-+.
......O.#.
#.........
......#...
```

選項三，在右下象限的站立式辦公桌旁邊放一箱煙囪擠壓原型織物：

```text
....#.....
....+---+#
....|...|.
..#.|...|.
..+-+-+#|.
..|.|.|.|.
.#+-^-+-+.
.+----+O#.
#+----+...
......#...
```

選項四，在左下角附近放一個煉金逆向渦輪增壓器：

```text
....#.....
....+---+#
....|...|.
..#.|...|.
..+-+-+#|.
..|.|.|.|.
.#+-^-+-+.
..|...|.#.
#O+---+...
......#...
```

選項五，將煉金逆向渦輪增壓器改放在右邊一點：

```text
....#.....
....+---+#
....|...|.
..#.|...|.
..+-+-+#|.
..|.|.|.|.
.#+-^-+-+.
....|.|.#.
#..O+-+...
......#...
```

選項六，在萬能溶劑罐旁邊放一罐至尊膠水：

```text
....#.....
....+---+#
....|...|.
..#.|...|.
..+-+-+#|.
..|.|.|.|.
.#+-^-+-+.
.+----++#.
#+----++..
......#O..
```

只要你和歷史學家們能在守衛不注意的情況下將其放置到位，你選擇什麼作為障礙物並不重要。重要的是要有足夠的選項，以便你可以找到一個將時間悖論降至最低的選項，而在這個例子中，你可以選擇 `6` 個不同的位置。

你需要通過添加一個新的障礙物讓守衛陷入循環。**你可以為這個障礙物選擇多少個不同的位置？**
