# --- 第 6 天：守衛漫步 ---

歷史學家們再次使用了他們那花俏的[裝置](https://adventofcode.com/2024/day/4)，這次是把你帶到了北極原型套裝製造實驗室……在 [1518](https://adventofcode.com/2018/day/5) 年！事實證明，對於一群歷史學家來說，能夠直接接觸歷史是非常方便的。

你仍然必須小心時間悖論，因此在歷史學家們尋找首領的同時，避免遇到 1518 年的任何人是很重要的。不幸的是，有一名**守衛**正在實驗室的這個區域巡邏。

也許你可以提前算出守衛會去哪裡，這樣歷史學家們就可以安全地進行搜索？

你首先製作了一張情況地圖（你的謎題輸入）。例如：

```text
....#.....
.........#
..........
..#.......
.......#..
..........
.#..^.....
........#.
#.........
......#...
```

地圖上用 `^` 顯示了守衛當前的位置（表示從地圖的角度看，守衛目前面朝**上**）。任何**障礙物**——板條箱、桌子、煉金反應堆等——都顯示為 `#`。

1518 年的實驗室守衛遵循非常嚴格的巡邏協議，其中包括重複遵循以下步驟：

- 如果你正前方有東西，向右轉 90 度。
- 否則，向前邁一步。

遵循上述協議，守衛向上移動幾次，直到她到達一個障礙物（在這種情況下，是一堆失敗的套裝原型）：

```text
....#.....
....^....#
..........
..#.......
.......#..
..........
.#........
........#.
#.........
......#...
```

因為現在守衛面前有一個障礙物，她在繼續沿著新的朝向直行之前先向右轉：

```text
....#.....
........>#
..........
..#.......
.......#..
..........
.#........
........#.
#.........
......#...
```

到達另一個障礙物（一卷**非常**長的聚合物）後，她再次向右轉並繼續向下移動：

```text
....#.....
.........#
..........
..#.......
.......#..
..........
.#......v.
........#.
#.........
......#...
```

這個過程持續了一段時間，但守衛最終離開了地圖區域（在走過一罐萬能溶劑之後）：

```text
....#.....
.........#
..........
..#.......
.......#..
..........
.#........
........#.
#.........
......#v..
```

通過預測守衛的路線，你可以確定實驗室中的哪些具體位置將位於巡邏路徑上。**包括守衛的起始位置**，守衛在離開該區域之前訪問過的位置標記為 `X`：

```text
....#.....
....XXXXX#
....X...X.
..#.X...X.
..XXXXX#X.
..X.X.X.X.
.#XXXXXXX.
.XXXXXXX#.
#XXXXXXX..
......#X..
```

在這個例子中，守衛將訪問你地圖上的 `41` 個不同位置。

預測守衛的路徑。**在離開地圖區域之前，守衛將訪問多少個不同的位置？**
