# --- 第二部分 ---

當你掃描損壞的記憶體時，你注意到一些條件語句也仍然完好無損。如果你處理程式中一些未損壞的條件語句，你或許能得到更精確的結果。

你需要處理兩個新的指令：

- `do()` 指令會啟用後續的 `mul` 指令。
- `don't()` 指令會停用後續的 `mul` 指令。

只有最近的 `do()` 或 `don't()` 指令會生效。在程式開始時，`mul` 指令是啟用的。

例如：

```text
xmul(2,4)&mul[3,7]!^don't()_mul(5,5)+mul(32,64](mul(11,8)undo()?mul(8,5))
```

這段損壞的記憶體與之前的例子相似，但這次 `mul(5,5)` 和 `mul(11,8)` 指令被停用了，因為在它們之前有一個 `don't()` 指令。其他的 `mul` 指令正常運作，包括最後一個被 `do()` 指令重新啟用的指令。

這次，結果的總和是 `48` (`2*4 + 8*5`)。

處理這些新指令；如果你只將啟用的乘法運算結果相加，你會得到什麼？
