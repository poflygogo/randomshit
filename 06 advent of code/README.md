這裡放置一些我在 Advent of Code 寫的解答

## 關於 Advent of Code

Advent of Code 是一個每年 12 月以聖誕節為主題舉辦的程式解題活動，從 12 月 1 日到 25 日每天都會釋出一道程式題目。這個活動由 Eric Wastl 創辦，旨在提供一個有趣的方式讓大家練習解決問題的能力。

Link: [傳送門](https://adventofcode.com/about)

### 活動形式

時間: 從每年的 12 月 1 日開始，每天的晚上 00:00(EST) 準時發布新題目(台灣時間是 13:00)

謎題結構: 每道謎題通常包含兩個部分(part 1 和 part 2)

- Part 1 通常較為簡單，解開後才能看到 Part 2。
- Part 2 是 Part 1 的變體或延伸，通常需要更複雜的邏輯、演算法優化，或考慮更多邊界條件 (edge cases)。

成功解出一個部分的謎題會獲得一顆金星 (Gold Star)

### 程式語言限制

沒有

可以使用任何程式語言來解決問題，然後把你的答案複製貼上後送出即可。
