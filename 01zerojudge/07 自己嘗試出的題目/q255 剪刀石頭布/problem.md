# q255. 剪刀石頭布 - 數手指

## 內容

有一群人聚在一起玩剪刀石頭布，但這次我們不在乎他們的輸贏，我們要根據他們伸出來的手指總數判斷他們具體出了什麼。

例如有 5 個人一起猜拳，2 個人出剪刀，2 個人出布，1 個人出石頭，則他們一共出了 5*2 + 2*2 = 14 根手指。

## 輸入說明

輸入包含多組測資。

第一行為一個整數 n，表示接下來會有 n 組測資。

(0 < n < 100)

接下來有 n 行，每組測資一行，每一行會有兩個正整數 a, b，用空格隔開。

a 代表玩家人數，b 代表一共有幾根手指。

(0 <= a, b < 2^32)

## 輸出說明

每組測資輸出一行，每行會在開頭先輸出一行訊息 "Game nn:"， n 的意思是這是第幾組測資，若 n 為個位數，請在 n 的前方補一個 0。

之後空一格，輸出一個數字，代表一共有幾個人出石頭，如果有多個可能的結果，請輸出最小的值。

若無法推測出合理的組合，請輸出 "Invalid"。

---------------------------------------------------------

## 解題思路

剪刀人數 a = (m - 5n) // 2 ，能整除的就是出剪刀的人數。

布人數 b = (m - 2a) // 5

石頭人數 c = n - a - b


## murmur

目標生成 10 組測資
- 前 5 組測資保證 0 < n < 10，a, b < 100，並保證不會出現無解的情況。
- 第 6-8 組測資 0 < n < 100，a, b < 1000，並保證不會出現無解的情況。
- 第 9-10 組測資 0 < n < 100，a, b < 2^32有可能出現無解的情況。

special case: 當 a, b 均為 0 時，應輸出 0
