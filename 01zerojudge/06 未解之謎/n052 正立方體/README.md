## 解題思路

正立方體的展開圖有以下幾種形式(忽視對稱/旋轉的版本)


(4, 1, 1)

```
□ ■ □ □     ■ □ □ □
■ ■ ■ ■     ■ ■ ■ ■
□ ■ □ □     ■ □ □ □

■ □ □ □     ■ □ □ □     ■ □ □ □     □ ■ □ □
■ ■ ■ ■     ■ ■ ■ ■     ■ ■ ■ ■     ■ ■ ■ ■
□ ■ □ □     □ □ ■ □     □ □ □ ■     □ □ ■ □
```

(3, 2, 1)

```
■ ■ □ □     ■ ■ □ □     ■ ■ □ □
□ ■ ■ ■     □ ■ ■ ■     □ ■ ■ ■
□ ■ □ □     □ □ ■ □     □ □ □ ■
```

(2, 2, 2)

```
■ ■ □ □
□ ■ ■ □
□ □ ■ ■
```

(3, 3)
```
■ ■ ■ □ □
□ □ ■ ■ ■
```

最後一種不能放在4x4的方格內，故不用考慮該形式。
