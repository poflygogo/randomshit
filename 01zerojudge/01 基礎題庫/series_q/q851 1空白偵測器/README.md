#

## 解題思路

大概整理了一下規則

1. 子母與字母之間最多只能有1個空格，若出現兩個或以上，則僅保留最右側的空格，其他的以 `*` 取代

    ```text
    I have    a  pen.
    I have*** a* pen.
    ```

2. 字串末端若有多餘的空格，則全部用 `*` 取代

    ```text
    (這邊為了方便理解，用底線表達空格)
    I_have_a_pen.__
    I_have_a_pen.**
    ```

3. 若多餘的空格出現在字串開頭，則分成兩種狀況處理
    - 若多於空格長度大於等於 2，則使用狀況 1 的方式處理

        ```text
        (這邊為了方便理解，用底線表達空格)
        ___I_have_a_pen.
        **_I_have_a_pen.
        ```

    - 若多於空格長度等於 1，則將其取代為 `*`

        ```text
        (這邊為了方便理解，用底線表達空格)
        _I_have_a_pen.
        *I_have_a_pen.
        ```

也可以使用另個思考方向

- 遍歷一次字串，當出現「連續的空格時」(空格長度 > 1)，就將其替換成 `*`，僅保留最後一個空格
- 遍歷結束後，檢查字串首尾的狀態，如果首尾的位置是空格，將其標記為 `*`
